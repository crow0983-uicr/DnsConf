# Карты

Концепты, исходники и заметки по большим картам.

Для каждой карты заведите отдельную папку (`maps/<название>/`) с файлом `README.md`:

- реальный прототип местности (если есть) и масштаб;
- размер карты в километрах;
- ключевые объекты: дороги, мосты, высоты, населённые пункты, склады;
- задумка по логистике: откуда идёт снабжение у каждой стороны.
