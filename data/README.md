# Данные с реальными ТТХ

Здесь хранятся таблицы с реальными характеристиками техники и вооружения. Это **источник истины** для баланса мода: игровые значения выводятся из этих таблиц, а не наоборот.

## Правила

- Один CSV на категорию (например, `units/tanks.csv`, `units/atgm.csv`).
- **У каждой строки должен быть источник** (колонка `source`). Без источника значение не принимается.
- Расстояния в **метрах**, скорости в **км/ч**, массы в **кг**.
- Если данные расходятся между источниками, пишем консервативное значение и отмечаем это в `notes`.

## Шаблон

См. [`units/units_template.csv`](units/units_template.csv).

| Колонка | Смысл |
|---|---|
| `id` | Внутренний идентификатор |
| `name` | Название образца |
| `nation` | Страна |
| `category` | Танк, БМП, ПТРК, САУ, ЗРК, БПЛА и т. д. |
| `weapon` | Основное вооружение или боеприпас |
| `range_effective_m` | Эффективная дальность огня |
| `range_max_m` | Максимальная дальность |
| `detection_range_m` | Дальность обнаружения своими сенсорами |
| `speed_road_kmh` | Скорость по дороге |
| `speed_offroad_kmh` | Скорость по пересечённой местности |
| `fuel_range_km` | Запас хода |
| `ammo_load` | Боекомплект |
| `source` | Ссылка или название источника |
| `notes` | Примечания |
